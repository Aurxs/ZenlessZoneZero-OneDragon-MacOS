# 零号空洞局内手柄事件

以下各画面取自「施工废墟·内部」。右侧较长的黄色条是当前选项，左侧绿色 A 随焦点所在行移动。卡片类型或物品名称可能随本局变化。

| 状态 | 画面判据 | 手柄操作和后续状态 |
|---|---|---|
| 呼叫增援 | 右栏标题为「呼叫增援！」，正文下方列出回应的代理人。队员头像在底部 | A 接应进入位置选择，也可选拒绝及对应的支援物资 |
| 增援位置 | 右栏出现「请选择代理人位置」和可选位置 | A 选择当前行，进入加入队伍的单按钮提示 |
| 增援结果 | 居中提示本次代理人已加入队伍，下方黄色「确认」及 A「选择」 | A 确认回棋盘 |
| 增援物资 | 代理人道别后出现「选择所需的物资」，列出三项免费随机获得指定类型鸣徽的配方 | 上下选择类型，同排 A 领取 |
| 邦布商人 | 右侧有「本店只收齿轮硬币」、鸣徽交易和鸣徽催化，右下 B「返回」 | B 直接回棋盘 |
| 压力过载 | 「受到侵蚀」后附症状名称，下方有对应说明。实拍症状包括震慑、抗性衰弱和蛮横 | A 关闭信息提示 |
| 投机客援助 | 「请选择一项援助」下方为「恢复身体」及「清除压力」，各有对应的生命值或压力值说明 | 上下移动焦点，A 领取当前援助 |
| 篝火休整 | 邂逅格显示「篝火如家般温暖」。正文先说明找到休整区域，再显示全队回复 20% 生命值 | 两段正文各按一次内联 A，游戏返回棋盘 |
| 怀斯塔学会的援助 | 安全点依次出现抵达、学会离开、接受好意、休整、战利品及全队恢复。唯一选项是「接受学会的好意」 | 每段按对应的 A，赠礼选项须有同排焦点 |

| 通用音频数据卡 | 独立界面标题为「通用音频数据卡」，底部左侧有播放快捷键，中部有 B「返回」 | B 关闭收藏品预览并返回棋盘 |
| 特殊区域播报 | 「特殊区域」播报的正文可为紧急委托、物品目标与入口说明，也可显示当前区域代号。实拍包括紧急委托 UC-0011 和区域代号 0018 | 纯告知页使用内联 A 推进，读完回到棋盘 |

| 坍塌的房屋 | 「事件」标题栏下有三项。强行拜访获得 600 齿轮硬币，钻入夹缝通道获得 1400，摧毁危楼注明资源可能受损 | 上下移焦后，使用同排 A 确认。手柄版「夹缝通道」对应原事件配置的「狭缝通道」。结果仍用同一标题，内联 A 推进正文 |

| 获得邦布插件 | 中央标题「获得邦布插件」、物品和数量，按钮文字为「确定」 | A 确认回棋盘 |
