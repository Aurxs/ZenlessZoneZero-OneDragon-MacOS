# Mac 式舆防卫战

原式舆应用通过 Mac 手柄分支进入剧变节点。通用选队规则、自动战斗策略、挑战记录和奖励流程继续由原应用管理。

## 选关和配队

快捷手册的作战标签下选择「式舆防卫战」。先确认剧变节点的完整标题和同卡黄色「前往」，再核对传送弹窗。首次到达选关页时，奖励图标有红色叹号就先走原手柄领奖操作。确认领取后继续挑战。选关页用剧变标签里的完成进度计算下一防线，用唯一的黄色环形焦点确认当前节点。进入后重新读取防线标题。第一至第四防线使用普通双队流程。

双队属性读取自各队「推荐属性」和「强敌抗性」区域。原式舆评分器在当前账户已同步的三人预备编队中选择互不重叠的队伍。通过既有手柄分页定位，在卡片上核对实际成员和 TEAM 01、TEAM 02 两个顺序标记。已选卡片与活动卡片同时有黄框时，按活动卡标题栏的 RS 或 Y 提示区分焦点。Start 确认预备编队，返回双队准备页且上阵人数为 6/6 后才另行出战。账号与游戏内编队不一致时停止，先使用原预备编队同步入口。

## 战斗和记录

每个半场单独加载对应编队的自动战斗策略。先从战斗 HUD 核对队员，再开启现有的 Mac 战斗输入保护。接敌使用原式舆距离判断和移动节奏，倒计时连续五秒消失后检查层间目标。层间移动按实际目标偏差和镜头校准转向。门前的原交互图标和左侧绿色 A 同时出现后，停掉战斗输入并只交互一次。过场后以实际下一队头像确认换队，最终以「消灭所有敌人」同行的完成比例确认胜利。退出结算后，只有选关页进度已推进才记录完成。领奖沿用手柄剧变奖励操作。

开发时可用生产操作 `GamepadShiyuBattle(..., resume_between=True)` 续接当前层间画面。入口会复核当前编队、无倒计时和层间距离或交互图标。

## 第五防线

第五节点的盾形徽章盖住一部分黄色焦点环，以外环四个象限的覆盖核对焦点。三间均待挑战时，原式舆属性评分器一次规划三支互不重叠的三人预备编队。进入具体房间时按实拍顺序选择房间、处理首次规则说明、确认房间号和零分并进入单队准备。每间出战前核对 3/3，结算退出后从房间列表读取本间的新成绩，同时核对其他成绩。三间都有成绩后回到选关，游戏显示 5/5 才记录第五防线完成。

已有部分成绩时，逐个核对有分房间前三格的代理人头像。头像使用原有连携图和各皮肤变体，匹配置信度须达到 0.92，且比第二个候选角色至少高 0.10。任一头像不清楚或角色重复时，保留成绩并报告待核对。全部读准后，从预备编队中排除与已锁角色有交集的队伍，零分房间才进入原属性评分和挑战流程。读数以当前游戏画面为准。目标预备编队在当前页有唯一同名卡且三名成员顺序一致时，可直接定位。随后按原流程核对选中回执与满员准备页。

第五防线已用实拍回放验证焦点、三个房间的属性与零分，以及房间一经规则说明进入单队准备。第一间实机取得 A 和 16881 分，生产操作返回列表并核对分数。使用这张有分画面回放原评分器，可识别已锁的三位代理人并为第二、第三间生成计划。重启后沿续打计划完成其余房间仍待实机验证。

## 验证

已用本机实拍回放作战标签、式舆分类、剧变卡片传送、当前进度 3/5、第四防线详情、两队属性和预备编队成员。原应用 2026-11-28 的首次实机执行连续到第四防线和 TEAM 01，随后停在第二队焦点识别。活动提示判定修复后，从第四防线详情执行双队核对、准备及出战。6/6 待战和 0/0 空队已用实拍回放核对。上半场自动战斗后曾停在距门 19.2 米处。校准转向恢复到门前后，生产操作从交互图标出现的现场继续，并识别进入下半场编队。第四防线分段实机取得 S，结算操作返回选关并核对进度从 3/5 到 4/5。主任务后续实机结果记在[迁移进度](../macos_migration_progress.md)。
