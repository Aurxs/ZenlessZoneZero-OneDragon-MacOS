# Mac 驱动盘拆解

原驱动盘拆解任务在 Mac 复用「拆解等级」与「全选已弃置」设置。入口走功能导览 → 仓库。若库存先停在音擎页，只用 RB 切到驱动仓库。菜单键打开拆解前，先读到「驱动仓库」和对应的「拆解」按钮。

拆解页要求选中数为零且「显示已装备」为 OFF。快速选择面板分别识别黄色焦点、蓝色已选条件和候选数，逐项核对当前选择符合原设置。零候选直接返回，核对驱动仓库数量后再经功能导览回大世界。

有候选时，X 应用筛选。应用后核对实际选中数，单次容量以游戏显示为准。LT 打开游戏原生「驱动拆解说明」，核对未装备、未锁定两个条件，以及快选容量。B 退出说明后复核选中数、装备显示状态和启用的拆解按钮。流程保存拆解前态后请求打开确认。

已建档的 A 级确认要求同时看到驱动盘文案、黄色「确认」和底栏 A「选择」。获得页用稳定的标题、母盘数量和确认提示核对返还，连续两帧确认后发送 A。回到拆解页先核对选中数归零，再在驱动仓库核对实际库存减少量。遇到其他品质的确认文案时保留画面并结束。

2026-11-28 手柄生产流程实测「A 及以下」且未勾选弃置盘。零候选流程核对库存后返回大世界。有候选时，流程选中并拆解 5 个驱动盘。首次获得页关闭落在动画淡入，后续从同一获得页续接，核对返还的 5 个母盘，读取当前驱动仓库数量并返回大世界。正向验收为两段，依据是选中数和实际返还。当前实现完整运行时也保存拆解前后的驱动仓库数量。
