# Mac 零号业绩速刷

## 固定路线的出战准备

从快捷手册抵达「深层调查」公共入口，核实右侧「枯萎之都」当前焦点及 A 提示。区域页通过标题和黄箭头定位「施工废墟」，难度列表逐行核对黄框，选中原速刷配置指定的「施工废墟·内部」后用菜单键打开六人准备页。

使用游戏中已保存的初始阵容。原速刷配置的目标代理人供局内调度支援，自动战斗读取原策略。手柄准备操作停在明确的出战页，主任务调用方负责后续确认。

准备阶段以原 OCR 和画面区域回放了公共入口、三个区域焦点、施工废墟两个难度焦点和最终准备页。

游戏保留「施工废墟·内部」行动时，区域图会锁定其他区域，难度页也只开放该项。下一步后的继续弹窗同时核对完整任务名称、确认焦点和 A 提示。继续后的棋盘或局内事件确认了本次续接。

## 局内逐格探索

沿用原枯萎之都模型和速刷寻路。每次从当前格的确认相邻边选择一个方向并保存前图。新画面按相对行列核对不同类别的棋格，允许镜头重排以及经过的行列消失。窄段进入硬币格时，也可由剩余棋格位置和独立的压力、齿轮硬币增量确认。进入了已核实的同名事件时，由该事件画面确认最后一步。找不到可靠相邻路线或画面状态不明确时，保存现场并结束本次探索。

开场鸣徽与特性聚合沿原鸣徽优先级。右侧事件需要已确认的继续 A 或唯一填充焦点下的同排 A。投机客借款菜单定位「不需要借款」，普通事件优先采用其原配置中的离开选项。

开发用的独立探索操作支持指定格数。已核对的格数与周常完成记录各自独立，后续运行可在已保留的本局继续。

原「零号业绩速刷」应用的 Mac 分支每十二格汇报进度，在同一局模型和寻路状态下继续探索。进入明确战斗格时最多等待三十秒过场，确认真实手柄 HUD 后再接原战斗。终止结算的 B 完成会进入枯萎区域选择，应用逐层经公共入口回到街区。原应用只在保存终止结算并核实回到街区后记录一次每日进入次数。

从已确认的施工废墟战况可用 X 暂离。「是否确认暂停空洞探索，返回街区」弹窗的确认焦点和再次到达街区共同验证暂离，当前局由游戏保留。

选关完整经过六人准备页后，出战操作发送一次菜单键。看到首个鸣徽选择或实际棋盘才算抵达局内。战斗接敌与策略由原零号空洞战斗操作处理，Mac 在有效手柄 HUD 下运行，并在退回结算或棋盘时释放战斗输入。独立速刷整局仍需现场核对跨层、业绩目标和最终退出。

道中挑战结果只有核实「完成关卡 1/1」和当前 A 确定时才确认，随后等待下一层的画面。第一层 S 级结果含调查点数、邦布系统控件、丁尼和枯萎脉晶，进度仍由实际棋盘的业绩考察点及最终回执核对。

优先沿真实有向连边前往可达业绩考察点。早期分段实测曾在第三层进入后续阶段时退出。那次实拍的终止结算显示邦布系统控件、丁尼和枯萎脉晶，独立零号业绩增量仍未核实。该结果结束当次等待，保持周满和通关次数，界面仍不宣称速刷周目标已验收。

从棋盘读取实际楼层后才调用原规划。同一楼层、地标和压力/齿轮硬币回到相同状态时，最近走过的方向不再重发。手柄分支只从原地图有向连边中选择能抵达可见业绩考察点或原目标的另一条路。第二层的实拍回放包含两个已反复往返的格子，两处都能通过上方相邻格改路。

同层展开新区域时出现近纯白的电视格。看到这种画面后保留一张诊断图，等待亮白消失且相对行列稳定后再规划或确认走格。

实拍的扭蛋机窄段在同层从三格收为两格。只有危机格相对于当前格移动一位，同时压力增加 10、鸣徽增加 1、齿轮硬币不变时，才确认本格移动。

棋盘侧邻红 S 门时，核对「开门」、上一场守门人 S 评条件、黄色焦点和 A 后开门。第二层实拍已识别局内获得的 30 零号业绩并在回棋盘后计入当局。终止页若没有这项物品，已核实的当局回执仍提供增量证据。已领取的楼层优先回主线，续接遇到已核实的诡雾短环也可改走真实出口。新开的探索从空回执开始。

### 2026-11-28 第二层考察点实际到账

在施工废墟·内部通过第一层守门战后，第二层寻路沿实际相邻格前往业绩考察点。红色 S 门须先在相邻格对准「开门」，游戏的通行条件为上一场守门人战斗获得 S 评价。通过门后抵达考察点，游戏在棋盘上方弹出「获得」窗口，名称为「零号业绩」，数量为 30。手柄流程留存该帧并确认，返回棋盘后本局计入 30 一次。该笔奖励在局内直接到账。此前只有邦布系统控件、丁尼和枯萎脉晶的终止结算，不能用来判断这笔奖励。

同一局到达第三层后，通过 S 门并取得第二张「零号业绩」回执，数量为 120。生产探索流程自动核实本层停止条件，退出流程读取终止结算、返回街区。两张局内回执共 150；因修复后分段续接，最后一段自动结算只携带第三层的 120。原应用从大世界单次连续完成到下一局的实机验证仍待完成，GUI 和 CLI 保持未开放。
