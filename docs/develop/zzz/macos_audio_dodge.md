# Mac 声音闪避

开发与验收遵循[Mac 手柄迁移约定](macos_gamepad_workflow.md)，本机结果统一记入[迁移进度](macos_migration_progress.md)。本文说明实现和现场判定方法，不代替实机验收记录。

## 实现与范围

`AutoBattleDodgeContext` 在 Mac 上构造 `MacAudioRecorder`，沿原自动战斗、闪避助手的开始、暂停、恢复、停止与关闭生命周期工作。仍使用三个正式 WAV、原高通滤波、半秒缓冲、相关系数和 `0.1` 阈值。普通提示和 X 提示可发出原「闪避识别-声音」事件，紫光只分类；画面红黄光仍按原规则优先判定。

录音订阅当前控制器已有的 `MacWindowCapture`，在同一 `SCStream` 上增删音频输出并更新 `capturesAudio`，不另建桌面采集流。过滤器仍绑定已核对的 bundle ID、PID 和窗口 ID。Apple 说明单窗口过滤器采集该窗口所属应用的声音，包括该应用其他窗口的声音；它不是整个系统默认扬声器的回放。[Apple WWDC22](https://developer.apple.com/videos/play/wwdc2022/10155/)

SCK 请求 48 kHz、双声道并关闭麦克风。按样本实际 ASBD 和 AudioBufferList 读取小端 float32 PCM，兼容交错与平面声道，先复制、逐帧取平均，再用连续 FIR 转为 32 kHz。滤波尾部和抽样相位跨回调保留，不逐块调用会补零的 `resample_poly`；固定滤波延迟为 10 个目标样本，约 0.313 ms。原生内存不离开回调。[Apple 音频配置](https://developer.apple.com/documentation/screencapturekit/scstreamconfiguration)

暂停和停止立即作废当前回调轮次并清空波形、滤波状态，再移除声音输出。原生呈现时间早于本轮订阅的数据会被丢弃；样本超过半秒、窗口失活、权限/格式错误或采集终止时停用本轮声音并提示，继续画面识别。恢复运行会重新订阅。样本时间断开或采样率改变时重新开始缓冲，不把两段声音拼接。没有音频时不回退麦克风、默认输出设备或 Windows 录音库。

`window_capture.audio_error` 独立记录音频错误，不覆盖视频的 `last_error`。全窗口采集停止会释放视频和音频；单独停止声音保留视频流。

## 离线验证

聚焦测试在独立测试仓 `test/tools/macos/test_sck_audio.py` 与 `test_macos_dodge_audio.py`。覆盖真实 CoreMedia 内存样本的三种声道布局、连续重采样与抗混叠、正式三模板分类、声音消费一次、暂停恢复、迟到回调、样本时间断开/过期、配置失败与图像回退。内存样本测试不枚举窗口、不打开任何设备；正式 WAV 回放只证明数字链路，不证明已识别游戏现场的提示。

## 现场正样本的最小验证

1. 先确认只有当前 GUI 或正式 CLI 占用游戏采集与手柄，沿已有准备游戏流程进入手柄模式。使用现有无体力消耗训练场或用户当前授权的战斗，不为声音检查额外消耗每日/每周次数。
2. 现场核对游戏内主音量和音效音量非零。历史记录曾将游戏主音量设为 0，不能据此假定当前有声。声音设置和是否恢复以当前用户要求为准，系统扬声器音量不代表应用实际输出。
3. 由原自动战斗/闪避助手启动声音订阅。若需诊断，只在当前 `dodge_context.get_max_corr(y)` 的调用处记录传入的半秒单声道波形、三个相关系数和分类结果，保持原返回值；不要新开一个录音器或采集进程。诊断最长 10 秒，最多保留 20 个候选窗口，数据只存本机 `.debug/`。
4. 观察真实敌方攻击提示。正样本须同时满足当前游戏的真实声音回调持续到达、对应波形有声、正式匹配器最高相关系数超过 `0.1` 并分类正确。普通/X 提示还需核对生产状态记录中的声音事件；画面闪光优先时可分别记录声音分类命中和本次实际采用的画面事件。只有输入波形非零、扬声器有声或模板数字回放均不能算实机正样本。
5. 暂停后确认 `recorder.running == False`、声音回调解除、缓冲为空或已清零，视频仍可采集。恢复后重新等待当前声音，上一轮提示不得直接重触发；停止和关闭后确认声音输出已移除。故意检查不可用状态时只做一次，不反复请求权限或消耗战斗机会。
6. 保存实际观察的提示类别、最高相关系数、声音事件/画面事件及暂停恢复结果。未出现的普通、紫光、X 类别逐项记待条件；静音、没有攻击提示或录音失败只证明相应负路径，不记为声音闪避通过。
